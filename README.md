Depois de 20 anos de experiência com Delphi / Lazarus / FreePascal, estou retornando aos estudos com C# e .Net.

C# não é exatamente uma linguagem nova para mim - Por volta de 2007 ou 2008 desenvolvi um emissor de NFe (Nota Fiscal Eletrônica) em C#, devido ao fato de que, à época, ainda não existiam ferramentas (e muito menos documentações) sobre o tema disponíveis em Delphi.

De lá para cá, muuuita coisa mudou. Muita coisa foi adicionada á linguagem e eu, enquanto me desenvolvia no Delphi acabei ficando "para trás" nas novidades que o mercado trouxe.

Neste momento, retorno aos estudos, com o prazer que sempre tive em aprender. Estou usando como base a sequência de livros do Mark Price, iniciando pelo livro intitulado C# 14 and .NET 10 - Modern Cross-Platform Development Fundamentals, Tenth Edition.

Meu objetivo com este repositório é tão somente registrar meus exercícios e aprendizados, uma espécie de "logbook" para que eu possa consultar eventualmente, caso se faça necessário.
